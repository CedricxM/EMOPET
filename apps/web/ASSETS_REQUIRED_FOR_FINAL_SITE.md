## Production Notes

### Image Optimization Pipeline
- All final images should be served as WebP with AVIF fallback
- Implement `<picture>` element with mobile/desktop srcsets
- Target: < 100KB per image on mobile, < 300KB on desktop
- Use `loading="lazy"` for below-fold images
- Use `priority` for hero image (LCP optimization)

### Video Guidelines (if used)
- MP4 with H.264 codec for compatibility
- Autoplay, muted, looping (no controls)
- Max 2MB per clip on mobile
- Provide static WebP poster frame as fallback
- Respect `prefers-reduced-motion`: show poster only

### Brand Color Context for Photography
- Backgrounds should harmonize with: `#FAF7F1` (cream), `#F4EFE6` (warm grey)
- Key accent in compositions: `#B46A4A` (terracotta) or `#6B8E6F` (sage green)
- Avoid: cool blues, high-contrast blacks, neon/saturated colors
