# EMOPET brand assets

Runtime assets for the web app live here so the UI never depends on files from
Downloads, Drive, or another local-only source.

Current source assets:
- `emopet-logo-dark.png` comes from the supplied `Logo_Dark.png`.
- `emopet-mat.png`, `emopet-tag.png`, `brand-identity.webp`,
  `brand-identity-core.jpg`, `branding-fr.png`, and `social-preview.png` come
  from the supplied presentation materials.
