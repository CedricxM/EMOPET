## Append-only rule

Existing ledger lines are immutable. New history is appended.

If an older record is wrong, append a `CORRECTION` event referencing `corrects_event_id`; do not edit the historical line.

The bootstrap record establishes the ledger from the current Company OS state and does **not** claim to reconstruct all state changes that happened before the ledger existed.

## Authority and confidentiality

A transition record can point to authority, evidence and decision refs, but cannot manufacture any of them.

The public ledger must never contain secrets, signatures, private contracts, bank details, personal data, confidential supplier material or restricted investor terms.
