# EMOPET Hardware Compliance Evidence Checklist

Status: `P0 CHECKLIST / NO CONFORMITY CLAIM`

Use one controlled copy per MAT/TAG hardware revision submitted to pre-compliance or formal conformity assessment.

## Identity and configuration

- [ ] Product name / revision
- [ ] Hardware revision
- [ ] PCB revision
- [ ] Enclosure revision
- [ ] Firmware revision / commit
- [ ] Bootloader revision
- [ ] Radio module(s) and antenna(s)
- [ ] Battery/cell/pack MPN
- [ ] Charger/power-supply configuration
- [ ] Intended use and foreseeable-use statement
- [ ] Markets/countries intended for launch

## Technical documentation

- [ ] Block diagram
- [ ] Schematics
- [ ] BOM with manufacturer part numbers
- [ ] PCB layout/stackup
- [ ] Mechanical drawings
- [ ] Materials declarations
- [ ] Software/firmware architecture
- [ ] Threat model and cybersecurity risk assessment
- [ ] Product safety risk analysis
- [ ] User instructions / safety warnings draft
- [ ] Label/marking draft
- [ ] Supplier declarations/certificates linked to exact MPN/revision

## Radio / RED

- [ ] Radio bands and maximum power
- [ ] Antenna type/gain/location
- [ ] Final enclosure/body-detuning test configuration
- [ ] RF exposure assessment where applicable
- [ ] Spectrum/radio test report
- [ ] EMC test report
- [ ] Safety test report
- [ ] EN 18031 applicability/gap assessment where applicable
- [ ] Final list of harmonised standards and Official Journal references verified at test date

## Cybersecurity

- [ ] No universal/default credential design or documented justification
- [ ] Pairing/provisioning controls
- [ ] Key storage architecture
- [ ] Secure boot status
- [ ] Firmware image signature verification
- [ ] Anti-rollback status
- [ ] Update-failure recovery
- [ ] Factory key provisioning/control
- [ ] SBOM
- [ ] Vulnerability disclosure process
- [ ] Security support period
- [ ] Incident reporting procedure

## Battery

- [ ] Battery classification
- [ ] Chemistry/capacity/voltage
- [ ] Cell/pack safety evidence
- [ ] Protection/charging design
- [ ] Removability/replaceability assessment
- [ ] Service instructions
- [ ] Spare-parts strategy
- [ ] Ingress vs repairability trade-off documented
- [ ] Final legal basis for any derogation verified

## Environmental / EEE

- [ ] RoHS declarations/material evidence
- [ ] Exemption register if any
- [ ] WEEE/EPR registration and marking plan by market
- [ ] End-of-life/take-back information

## Final release gates

- [ ] Applicable-legislation matrix signed off
- [ ] Applicable standards list signed off
- [ ] Test reports match production-intent hardware/firmware
- [ ] Deviations assessed
- [ ] Technical file complete
- [ ] EU Declaration of Conformity drafted/approved where applicable
- [ ] CE marking artwork/placement approved where applicable
- [ ] Serial/lot traceability operational
- [ ] Post-market incident/corrective-action process operational

Until every applicable final-release item is supported by controlled evidence, status remains `NOT CE RELEASED / NOT MANUFACTURING AUTHORIZED`.
