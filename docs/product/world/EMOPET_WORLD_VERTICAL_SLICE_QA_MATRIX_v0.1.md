## G. Unity kill-gate questions

After the session, ask:
1. Did being in a 3D shared place make meeting others more natural or memorable?
2. Did spatial exploration create enjoyment that a normal feed could not?
3. Did the personal space feel meaningfully “yours”?
4. Did the 3D dog representation add identity without implying emotion?
5. Would a 2D/social-only implementation provide the same value more simply?

If the fifth answer is consistently “yes,” Unity should be challenged rather than defended.
