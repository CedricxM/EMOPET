# EMOPET — WORLD SECOND ACTIVITY CONCEPT — LA FRESQUE COLLECTIVE v0.1

**Status:** PROPOSED CONTENT HOOK / NOT IMPLEMENTED

## 1. Purpose

Give players an immediate reason to remain together after `La piste commune` without using currency, streaks or competition.

## 2. Activity

**La fresque collective**

Players:
3–6 Guardians preferred, 2 minimum.

Duration:
5–8 minutes design target.

Mechanic:
- each player chooses one tile from a small curated set;
- each tile contains a visual element tied to the current regional chapter;
- players place tiles onto a shared wall;
- tile placement can be rearranged collaboratively;
- when the group confirms, a short transition completes the mural.

No “best tile”.
No score.
No voting against a player.

## 3. Persistent consequence

For the duration of the test session:
- completed mural appears in the Hub;
- participant names/pseudonyms may be listed only if opted in;
- each participant receives a small snapshot keepsake.

This tests:
- visible community impact;
- collective authorship;
- attachment to the Hub;
- reason to show another person “we made this”.

## 4. Moderation/content restriction

First slice:
- no user-uploaded images;
- no free-text on the mural;
- only curated visual tiles.

Reason:
avoid opening UGC moderation complexity before the core social mechanic is proven.

## 5. Dog role

Dog avatars remain nearby with neutral idle/waypoint behaviour.

No “painting”, emotional reaction or approval animation.

## 6. Why it complements `La piste commune`

`La piste commune` = explore + solve together.  
`La fresque collective` = create + leave a trace together.

Together they test two distinct social motivations:
- shared discovery;
- shared creation.
