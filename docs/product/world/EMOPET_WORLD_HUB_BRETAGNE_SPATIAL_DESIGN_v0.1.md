# EMOPET — WORLD HUB BRETAGNE SPATIAL DESIGN v0.1

**Date:** 2026-09-01  
**Status:** PROPOSED PRE-PRODUCTION DESIGN / FOUNDER REVIEW REQUIRED  
**Implementation:** NOT IMPLEMENTED / UNITY HOLD  
**Scope:** First vertical slice only

## 1. Design objective

The Hub must make four things obvious without a long tutorial:

1. **I have a place here.**
2. **Other people are really present here.**
3. **There is something to do together.**
4. **This place belongs to a real regional universe without becoming a caricature.**

The Hub is not a realistic Lorient replica. It is a stylized Brittany-rooted social space.

## 2. Spatial principle

Use a compact, legible **three-ring layout**:

### Ring A — Arrival / social orientation
Central arrival plaza.

Contains:
- spawn/arrival point;
- public activity board;
- visible path to personal space;
- one discovery landmark;
- 2–3 social seating/standing zones;
- human-avatar presence;
- no commercial storefronts.

### Ring B — Interaction belt
Surrounds the arrival plaza.

Contains:
- entrance to `La piste commune`;
- Community event portal;
- one temporary-event zone;
- one small customization preview point;
- one quiet social corner;
- block/report/profile interaction affordances.

### Ring C — Exit / extension paths
Short stylized paths that suggest a larger world without building it yet.

Contains:
- path toward personal space;
- path toward future regional zone;
- path toward future event area.

Only one branch is playable in v0.1. Others are visibly `COMING LATER` without countdown pressure.

## 3. Spatial memory landmarks

The Hub needs 3 recognizable landmarks:

### Landmark 1 — The central mast
A sculptural orientation object inspired by maritime forms without copying a real monument.

Use:
- as spawn reference;
- as party regroup point;
- as event announcement surface.

### Landmark 2 — The discovery arch
A stylized cultural-information gateway.

Use:
- source-backed content;
- regional stories;
- one discovery interaction;
- visible provenance access.

### Landmark 3 — The shared trail gate
Portal/entrance to `La piste commune`.

Use:
- group formation;
- invite status;
- ready state;
- clear “2–4 Guardians” label.

## 4. Movement scale

The Hub should feel populated even with a small test cohort.

Design target:
- 20–35 seconds maximum walking time across the playable space;
- most meaningful features visible from arrival or after one turn;
- no huge empty plaza;
- no open-world traversal in this slice.

## 5. Social density

Target visible instance size for first prototype:
**6–12 human avatars**.

This is a design target only, not a production capacity claim.

Rationale:
- enough to feel alive;
- small enough to avoid social overload;
- simple enough for moderated testing.

## 6. Human avatar interactions

Available in v0.1:
- wave;
- greet;
- invite to activity;
- inspect public profile;
- invite to personal space;
- mute;
- block;
- report.

Not available:
- freeform physical contact animations;
- automatic proximity friendships;
- passive exact-location sharing;
- voice chat;
- trading.

## 7. Dog-avatar placement

Dog avatar:
- appears beside/following the Guardian;
- never acts as a social status indicator;
- never displays mood;
- never chooses another player because of inferred “compatibility”;
- never reacts emotionally to another dog.

Neutral interactions only:
- follow;
- sit;
- lie down;
- waypoint movement;
- object inspect animation.

## 8. Breiz presence in the Hub

Breiz should not float beside the player continuously.

Preferred presence:
- contextual UI voice;
- optional kiosk/marker;
- short, relevant interventions.

Breiz may:
- orient first arrival;
- explain a source-backed discovery;
- explain how to join an activity;
- clarify privacy/visibility.

Breiz should not:
- narrate every movement;
- fill silence;
- comment on the dog’s internal state;
- auto-start social interactions.

## 9. Personal-space entrance

The entrance to `Mon espace` should be visually obvious from the Hub.

Transition:
- no loading fiction implying a real geographic home;
- user enters a private/personal instance;
- invite-only access for other Guardians.

The personal space is the emotional anchor of persistence.

## 10. Visual tone

Target:
- contemporary;
- warm;
- slightly stylized;
- regionally grounded;
- not fantasy medieval;
- not tourist-brochure Brittany;
- not photorealistic city simulation.

Avoid:
- permanent rain gimmick;
- crêpe/cidre visual spam;
- exaggerated folklore;
- Breton symbols used as decoration without context.

## 11. Audio direction

If audio is used:
- ambient regional texture may exist;
- no continuous dog vocalization;
- no emotional dog sound loop;
- no “sad whine” / “happy bark” state machine;
- social notification sounds must be restrained.

## 12. Accessibility requirements for slice

Minimum:
- readable text at mobile scale;
- color-independent interaction cues;
- subtitles for Breiz;
- reduced-motion option;
- camera sensitivity controls;
- no critical information conveyed only through 3D animation.

## 13. Success criterion

The Hub succeeds if a first-time user can, without a long tutorial:
- identify their personal space;
- identify another Guardian;
- understand how to join one activity;
- discover one regional content point;
- understand how to leave/block/report.
