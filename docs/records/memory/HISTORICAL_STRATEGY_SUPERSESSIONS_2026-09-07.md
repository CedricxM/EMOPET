# EMOPET — Historical Strategy & Supersession Memory

**Control date:** 2026-09-07  
**Status:** `CONTROLLED MEMORY / DO-NOT-REINTRODUCE WITHOUT NEW DECISION`

## Purpose

EMOPET has evolved rapidly. Several old ideas remain in historical presentations, BOMs, chats and supplier documents. They are valuable as lineage, but dangerous when reused as current authority.

This record preserves high-risk historical directions so future contributors or AI systems do not resurrect them accidentally.

## 1. Remote voice / TAG speaker

### Historical direction

Earlier TAG/BOM/public material included a speaker / remote voice concept and some public copy still described speaking to the dog remotely.

### Current controlled interpretation

The speaker/remote-voice hardware feature was retired from the current simplified TAG architecture in the recovered lineage.

The microphone/acoustic path is contextual/derived-signal only under the current privacy doctrine; raw household audio must not be treated as a product asset.

### Rule

Do not present remote voice as current V1 hardware merely because it appears in a July presentation or legacy BOM.

Any future voice-cue capability is a separately gated software/product workstream and requires explicit architecture, privacy, safety and hardware authority.

## 2. WQI / RSI naming

Historical/public copy created semantic drift.

Controlled lineage identified:

- **WQI** = Walk Quality Index, not a generic Wellness Quality Index;
- **RSI** = Routine Stability Index, not a Rest/Sleep Score Index.

### Rule

Do not reuse WQI/RSI labels in public/product copy without checking current scientific/product authority and whether those indices remain authorised at all.
